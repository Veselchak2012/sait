# Як редагувати теми уроків (без JavaScript)

Вам потрібно знати лише HTML + CSS.

## Де редагувати
- `class5.html` — теми для 5 класу
- `class6.html` — теми для 6 класу
- `class7.html` — теми для 7 класу
- `class8.html` — теми для 8 класу

## Структура однієї картки
У кожному файлі знайдіть блок:

```html
<article class="lesson-card">
  <img class="lesson-thumb" src="images/lesson-placeholder.svg" alt="Міні-зображення до теми уроку 1" />
  <h3>Тема уроку 1 (шаблон)</h3>
  <p>Короткий опис для уроку 1.</p>
  <a class="button" href="lesson.html?class=5&lesson=1">Перейти до уроку</a>
</article>
```

## Що можна міняти
1. **Назва теми** — текст у `<h3>`.
2. **Короткий опис** — текст у `<p>`.
3. **Міні-зображення** — шлях у `src="..."`.
   - Наприклад: `src="images/my-topic-1.jpg"`
4. **Номер уроку/посилання** — `lesson=1` у `href`.

## Як додати власні міні-зображення
1. Скопіюйте ваші картинки в папку `images/`.
2. У потрібній картці замініть:
   - `src="images/lesson-placeholder.svg"`
   на
   - `src="images/назва-файлу.jpg"`

## Якщо потрібно змінити стиль картинок
Відкрийте `styles.css` і відредагуйте клас `.lesson-thumb`.


## Як редагувати матеріали конкретного уроку
Тепер для кожного уроку є окрема сторінка-файл:
- `lessons/class5/lesson1.html`, `lessons/class5/lesson2.html`, ...
- `lessons/class6/lesson1.html`, ...
- `lessons/class7/lesson1.html`, ...
- `lessons/class8/lesson1.html`, ...

Відкрийте потрібний файл і редагуйте прямо в HTML:
- назву теми (`<h2>`),
- опис,
- посилання на презентацію,
- посилання на тест,
- вправи/практичну роботу.
